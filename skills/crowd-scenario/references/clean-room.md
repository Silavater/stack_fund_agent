# Clean-room provenance (honest version)

The **concept** of "heterogeneous personas reacting to an event → second-order
reaction chain + contrarian signal" was inspired by the open-source
`666ghj/MiroFish`. We **did not integrate its code** (AGPL-3.0 §13 would force
source disclosure to every paying user of a billed network service — incompatible
with this project).

**Honest clean-room standard actually met:**

1. To *understand* the architecture we reviewed MiroFish source, but **copied no
   code / prompt / schema text**. All field names, schemas, and the stance /
   contrarian formulas are original.
2. The design is re-argued from first principles (and as an extension of the
   `tw-stock-agent` contrarian layer), not as a shrunken MiroFish — no MiroFish
   module decomposition or private class names are referenced.
3. We ship MIT, stateless, never distributing MiroFish code → no §13 surface.

NOTICE: acknowledges the *idea* only. Legal risk is low; the real risk is
credibility if provenance were overstated — so it is stated plainly here.
